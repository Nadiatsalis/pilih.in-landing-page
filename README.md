# Pilih.in — Food Decision Assistant (MVP)

> \*\*Make better food choices every day.\*\*  
> Landing page validasi konsep Pilih.in yang dirancang untuk membantu pengguna memahami trade-off antara Diet/Health Fit, budget, dan Taste/Preference saat memilih makanan dalam situasi sehari-hari.

\---
## 🎯 Tujuan Project

MVP ini dibuat untuk memvalidasi konsep Pilih.in sebagai Food Decision Assistant, khususnya apakah membantu pengguna memahami pilihan dan trade-off sebelum mengambil keputusan makanan.

MVP berfokus pada validasi konsep melalui landing page dan form feedback pengguna, bukan membangun full-scale recommendation engine.

## 👤 Target User

Pilih.in ditujukan untuk orang dewasa yang sedang atau ingin menjalani pola makan tertentu dan membutuhkan bantuan dalam memilih makanan pada situasi sehari-hari, seperti:

* Saat makan di luar
* Saat sedang sibuk
* Saat budget terbatas
* Saat menghadapi banyak pilihan makanan

## 🚀 Fitur Utama

* **Landing Page Informatif: Menjelaskan masalah dalam memilih makanan dan konsep decision support berbasis trade-off.
* **Tabel Komparasi Interaktif**: Memberikan gambaran tentang bagaimana Pilih.in membandingkan opsi makanan.
* **Form Validasi Live**: Form interaktif 9 pertanyaan untuk mengumpulkan respons \& feedback calon pengguna.
* **Backend Sederhana (Google Sheets)**: Seluruh data pengisian form tersimpan secara otomatis dan real-time di Google Sheets via Google Apps Script.

\---

## 🛠️ Tech Stack \& AI Tools

* **AI Tool**: Gemini (Google AI)
* **Frontend**: HTML5, CSS3, Vanilla JavaScript (Fetch API)
* **Backend / Database**: Google Apps Script (Web App) \& Google Sheets
