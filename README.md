# Pilih.in — Food Decision Assistant (MVP)

> \*\*Make better food choices every day.\*\*  
> Landing page validasi konsep Pilih.in yang dirancang untuk membantu pengguna menganalisis trade-off antara kesehatan (nutrisi), budget (harga), dan selera (rasa) saat memilih makanan harian.

\---

## 🚀 Fitur Utama

* **Landing Page Informatif**: Menjelaskan masalah umum pencarian makanan dan solusi trade-off assistant.
* **Tabel Komparasi Interaktif**: Memberikan gambaran bagaimana Pilih.in membandingkan opsi makanan.
* **Form Validasi Live**: Form interaktif 9 pertanyaan untuk mengumpulkan respons \& feedback calon pengguna.
* **Backend Sederhana (Google Sheets)**: Seluruh data pengisian form tersimpan secara otomatis dan real-time di Google Sheets via Google Apps Script.

\---

## 🛠️ Tech Stack \& AI Tools

* **AI Tool**: Gemini (Google AI)
* **Frontend**: HTML5, CSS3, Vanilla JavaScript (Fetch API)
* **Backend / Database**: Google Apps Script (Web App) \& Google Sheets
